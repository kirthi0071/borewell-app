# Borewell Manager

Tamil/English Android app for borewell service businesses: jobs, customers, bills priced by depth, payments and dues, crew assignment, expenses and profit, WhatsApp reminders, PDF bills.

- Multi-business: each owner registers with a mobile number and gets an organization code; staff log in with code + username + password.
- Roles: **Admin** (everything), **Office** (no profit/settings), **Crew** (only their jobs, no money).
- Works offline and syncs later.

**Setup, signing and Play Store steps:** see [SETUP.md](SETUP.md).

```bash
npm ci && npm run dev:demo   # try it in the browser without Firebase
```
